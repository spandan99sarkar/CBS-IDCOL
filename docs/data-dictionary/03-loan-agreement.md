# Data Dictionary — Loan Agreement

> **Department:** BU/CRM  ·  **App route:** `/sanctions`  ·  **Backend module:** CreditSanction

## Purpose

The "Borrower Agreement" (Loan Agreement / Sanction) module has a List page and an Entry page with three modes (entry/edit/view). The Entry page is organized into four sections: (1) Core Information (Mandatory) — Sanction ID, auto-patched Proposed Business Unit, Product, Customer, Project, Industry Type, Loan Currency + amount, Grant Currency + amount, Agreement Signing Date, and an Availability Period with a By-Date / By-Months toggle that auto-computes the counterpart (expiry date <-> months, formula "Agreement Date + Months - 1 day"); (2) Optional Information — Interest Rate Type (Fixed/Float radio) with a repeating floating-rate components sub-table whose values auto-sum into a read-only Initial Interest Rate, Loan Tenor, No. of Principal Repayments, Interest Grace Period and Principal Moratorium Period each with a Day/Month/Year unit selector, Principal Repayment Method, Principal & Interest Payment Frequencies, Day Count Basis, LPC Rate; (3) Other Information — auto-patched Initiated/Approved by (BU), free-text Initiated/Approved by (CRM), Credit Rating, Remarks; (4) Agreement Related Documents — a repeating table of {document name, file upload}. When Loan or Grant currency = "Equivalent BDT" the form expands to capture a foreign currency + a foreign amount and a BDT-equivalent amount. The page implements agreement VERSIONING (v1..v4 selector; view mode is read-only historical, edit mode edits the current version, new = v1). Workflow actions are Clear and Save/Update Agreement. The List page shows Sanction ID, Customer (name+id), Product, Loan Amount (with BDT-equivalent shown when Equivalent BDT), Grant Amount, Loan Currency, Grant Currency, Signing Date, Availability Period (expiry date), No. of Principal Repayments, Status (Signed/Active/Pending), and per-row View-versions / Edit-current actions.

## Repeating / line-item tables

- Floating Rate Components (floatParts[]): columns = Name (e.g. LIBOR), Value % — repeating, auto-summed into Initial Interest Rate
- Agreement Related Documents (documents[]): columns = Document Name, File (upload) — repeating, add/remove rows
